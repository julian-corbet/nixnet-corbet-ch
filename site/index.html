nixnet

Still reachable when the mesh isn't.

nixnet is a small resident daemon and NixOS module that picks the best currently-healthy path to a host or a local uplink — LAN or VPN overlay, wired or cellular — and publishes the winner where ssh, mount, and everything else already look. It replaces the hand-rolled per-host failover script, and fills the one gap every mesh VPN daemon leaves open: what happens when the mesh itself is down.

How it works

1

Describe the transports

List every way to reach a peer, or carry an uplink — LAN, overlay, wired, wireless — each with a priority and a health check, in one declarative schema.

2

nixnetd probes, continuously

Every transport gets its own goroutine and its own ticker, so one slow or hung probe never delays another. A hysteresis state machine tells healthy apart from flapping.

3

The winner gets published

A peer's address lands in a managed /etc/hosts block; an uplink's interface gets the best route metric. Every tool that already worked keeps working.

Features

One schema, two tables

peers.<name> and uplinks.<name> share one transport type and one engine — not a bolt-on kind discriminator bolted onto a single pool.

Provider-agnostic by contract

A provider contributes ordinary list entries, optionally backed by an exec script — exit code plus one JSON line. No plugin loader, no core changes for a new mesh.

Hysteresis-damped

A minimum hold time stops nixnet switching away from a healthy winner just because a lower-priority option also came up — but a dead winner is never held onto.

No resolver, no listener

Peers publish into /etc/hosts, read by NSS files ahead of dns. Zero query-time protocol, zero coupling to whichever mesh daemon's own resolver is currently unwell.

Reprioritizes, never replaces

Uplink failover flips a route's metric field only — the gateway and every other attribute DHCP or a static config assigned is left exactly as it was.

Self-watchdogged

nixnetd calls sd_notify(WATCHDOG=1) on its own heartbeat; systemd force-restarts it if the event loop ever wedges — no bespoke supervision code.

Unprivileged by default

A peers-only install using TCP or HTTP probes gets zero elevated capabilities. CAP_NET_RAW is granted automatically, and only, when a transport actually needs it.

Ships a NetBird provider

Detects the local mesh identity going stale, or silently re-enrolling against the wrong endpoint, and re-provisions headlessly from a setup key — failing loudly, never silently, when it can't.

Providers, not plugins

A provider registers by contributing ordinary Nix list entries into services.nixnet.peers.<name>.transports. Core has no registry and no provider-specific code to fork.

One health contract

Built-in TCP, ICMP, and HTTP probes cover the common case. A provider needing richer health, or a dynamically discovered address, drops in an exec script: exit code plus one optional JSON line.

Reconverges from disk

Hysteresis counters and last-known winners persist to /var/lib/nixnet/state.json. A killed or restarted daemon rebuilds its picture correctly — no special recovery path.

Install

NixOS (flake)

Import the core module and turn it on. Providers are opt-in additional imports.

{
  inputs.nixnet.url = "github:julian-corbet/nixnet-corbet-ch";

  # host configuration.nix
  imports = [ inputs.nixnet.nixosModules.default ];
  services.nixnet.enable = true;
}

Non-NixOS (system-manager)

Same module file, same schema — nixnet touches only environment.etc and systemd units, nothing system-manager can't reach.

systemManagerModules.core = inputs.nixnet.systemManagerModules.core;

From source

The daemon is a static Go binary; the module is plain Nix.

git clone https://github.com/julian-corbet/nixnet-corbet-ch
cd nixnet-corbet-ch
nix build .#nixnetd

Commands

nixnetctl status Every peer and uplink group: current winner, per-transport health, and how long the winner has held.
systemctl status nixnetd Whether the daemon itself is up, and since when.
journalctl -u nixnetd -f Follow failover events live — one structured line per state transition.
cat /run/nixnet/status.json The same data nixnetctl formats, as raw JSON — for a script or a status page.
systemctl restart nixnetd Safe any time — every publish is a full atomic recompute, so a restart reconverges cleanly from disk.
