# studies

Written-up findings: things that were tried in
[`../experiments/`](../experiments/README.md), worked (or failed
instructively), and are worth recording properly — with the reasoning,
not just the result.

A study earns its place here once it changed a decision in the main
project. Nothing is written up here yet: the one question that has closed
so far (#006, NetBird's `status --json` field paths) closed by being
corrected against a real payload rather than by producing a finding worth
a write-up. Every still-open question lives in
`../experiments/README.md`. See the main
[README](../README.md) for the project itself, and
[`docs/providers.md`](../docs/providers.md#documented-deviations-and-judgment-calls)
for the judgment calls already made while writing the code — those are
decisions with their reasoning recorded, not experiments run against a
real deployment.
