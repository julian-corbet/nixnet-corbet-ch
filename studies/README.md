# studies

Written-up findings: things that were tried in
[`../experiments/`](../experiments/README.md), worked (or failed
instructively), and are worth recording properly — with the reasoning,
not just the result.

A study earns its place here once it changed a decision in the main
project. Nothing has closed yet — this is a fresh scaffold, and every
open question currently lives in `../experiments/README.md`. See the main
[README](../README.md) for the project itself, and
[`docs/providers.md`](../docs/providers.md) for the deviations already
made from the v1 design document during implementation (those are
documented judgment calls made while writing the code, not yet
experiments run against a real deployment).
