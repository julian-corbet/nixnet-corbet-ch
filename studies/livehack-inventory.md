# nixnet livehack inventory

64 unorthodox mechanisms, merged from four independent reads (Rust daemon, Nix modules, six months of git history, read-only live audit of corbet-server + CORBET-ELITEBOOK). Ordinary code has been dropped; everything here is a deliberate hack, a magic constant, or a place the source and the machine disagree.
Mark the last column `keep` / `kill` / `?`. Rows tagged **[DECLARED vs LIVE]** are direct contradictions between the declaration and the running machine — read those twice.
Answer these three first: **SEAM-1** (two writers on the hosts file — every peer alias is NXDOMAIN on both hosts right now), **TF-2** (the uplink/route-metric half has never once published in production — keep it or cut it), **TF-6** (`lastKnownGood` has no TTL — /etc/hosts has advertised a dead host since 2026-07-24).
